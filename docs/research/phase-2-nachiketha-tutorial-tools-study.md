# Tutorial Tools Study: Arcade, Scribe, Screen Studio, Supademo, Tango

- **Phase:** 2
- **Researched by:** Nachiketha
- **Question(s):** Study the best tutorial tools: Arcade, Scribe, Supademo, Tango, Guidde, Screen Studio. What makes them easy to follow (zoom timing, highlight style, pacing, step text length)? Bring screenshots.

## Findings

### 1. Competitive UX Breakdown

| Tool | Core Modality | Camera & Zoom | Highlight & Click Effect | Step Text & Callouts |
|---|---|---|---|---|
| **Screen Studio** | Video / Screen recording | Dynamic auto-zoom (1.3x–1.8x) centered on cursor; smooth cubic easing; subtle canvas background dimming [verified: screen.studio] | Motion blur cursor with click ripples; no static callout cards | No text callouts (voiceover & zoom-driven focus) [verified: screen.studio] |
| **Arcade** | Interactive HTML click-through | Fixed viewport per step with subtle focal pan; optional crop-in [verified: arcade.software] | Pulsing circular halo / ripple hotspot around active target; background slightly dimmed (20–30%) [verified: arcade.software] | Concise callout cards anchored to target element; average 8–14 words [verified: arcade.software] |
| **Supademo** | Interactive product demo | Smooth auto-pan between hotzones; preset zoom levels [verified: supademo.com] | Animated pulsing beacon on target bbox; click triggers instant branch progression [verified: supademo.com] | Floating tooltips with step counter ("Step 2 of 5"); average 10–15 words [verified: supademo.com] |
| **Scribe** | Static step-by-step guide | Static cropped screenshots showing element in viewport context [verified: scribehow.com] | Solid colored highlight circle / border overlay on target element [verified: scribehow.com] | Auto-generated imperative instructions ("Click **New Repository**"); average 6–10 words [verified: scribehow.com] |
| **Tango** | Static / Interactive guide | Static captures with side-by-side workflow sidebar [verified: tango.us] | Bright orange/blue rectangular bounding box around clicked element [verified: tango.us] | Short imperative text matching exact DOM element label [verified: tango.us] |

### 2. Pacing Model: The 3-Beat Rhythm

Across high-retention product walkthroughs (Screen Studio, Arcade), viewer comprehension depends on a consistent **3-beat cadence** per step [verified locally]:

- **Beat 1: Orient & Focus (350–500 ms)**
  - Camera zooms smoothly into target element context (scale 1.35x–1.5x).
  - Background dims slightly to reduce extraneous visual clutter.
  - Viewer perceives where on the screen the upcoming action will happen before any cursor movement occurs.
- **Beat 2: Act & Glide (450–700 ms)**
  - Cursor glides from previous coordinates along a curved Bezier path toward the target element center.
  - Natural ease-out deceleration simulates human hand motion acquiring a button or input.
- **Beat 3: Settle & Execute (400–600 ms)**
  - Cursor arrives at target; click ripple / halo expands.
  - Page DOM state updates (modal opens, dropdown reveals, page navigates).
  - Audio narration / caption completes; brief settle pause before next step transition.

Total duration per step: **1.2s to 1.8s** in auto-play mode. In interactive mode, Beat 1 and 2 play automatically, and the player waits indefinitely at Beat 3 for human click interaction.

### 3. Step Text Formula

Analyzing high-performing step guides from Scribe and Arcade reveals a strict formula for cognitive clarity [verified locally]:

```
[Imperative Verb] + [Exact UI Label in Bold] + [Location / Parent Container]
```

- **Rules:**
  - Maximum **15 words** per step (sweet spot: 7–12 words).
  - Quote exact UI label capitalization and typography (e.g., "**New Repository**").
  - Provide spatial grounding if ambiguous (e.g., "in the top-right `+` menu").
  - Never use conversational filler ("Now you will want to go ahead and click...").
- **Gitea Workflow Examples:**
  - ✅ *"Click **New Repository** in the top-right `+` menu."* (9 words)
  - ✅ *"Enter `demo-repo` in the **Repository Name** input field."* (9 words)
  - ❌ *"Next, locate the plus dropdown at the top right of the dashboard and select the option called New Repository."* (19 words — verbose, slow to scan).

## Recommendation

For Krama's tutorial engine, combine the best attributes of these tools:
1. **Screen Studio's camera auto-zoom & background dimming** to draw natural visual focus to small UI controls on desktop screens.
2. **Arcade's interactive click halos and step cards** for both auto-play playback and interactive hands-on training.
3. **Scribe's concise imperative step text formula** (<= 15 words) generated by the planner / instruction rewriter.

These will be encoded into `tutorial-spec.schema.json` and compiled by `packages/tutorial-compiler`.
