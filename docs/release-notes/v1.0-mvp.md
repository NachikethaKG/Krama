# Release `v1.0-mvp` (Phase 3 MVP)

Tag `v1.0-mvp` on `d309a2e` · https://github.com/NachikethaKG/Krama/releases/tag/v1.0-mvp

Phase 3 MVP: the PRD §41 experience on real GitHub. Ask in plain words, approve the plan, watch Krama do it in a real browser with every step checked, then learn from an interactive tutorial.

## What's in it
- **Real GitHub** through the test account's encrypted, stored browser session (Krama never has the password), plus a practice repository for tasks that need an existing one.
- **Accounts**: seeded sign-in, HTTP-only session cookie, CSRF header, every app page protected; per-user ownership of tasks, runs, tutorials and recordings.
- **A product UI**: a public landing page; one prompt ("What do you want to learn?") that works out the website from the words; plans in PRD §41 wording; live run with "Tutorial ready"; My tutorials and Runs in plain language.
- **Example values**: tutorials make up example names (`feature-docs-4821`) and present them as examples instead of asking the learner for their own.
- **Tutorials** replay the real recording (fixed: 401 on the recording, skipped steps, misplaced highlights from lost CSS).
- **Sharing**: read-only share links with revoke (created through the API for now).
- **Background jobs** (arq + Redis, optional), **metrics** (`GET /metrics/summary` and a dashboard), and `start-krama.bat` / `stop-krama.bat` to run everything locally.
