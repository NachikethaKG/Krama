# Release `v1.2` (Phase 5 Video Export)

Release: https://github.com/NachikethaKG/Krama/releases/tag/v1.2 · Tag: `v1.2`

Phase 5 Video Export: export any verified tutorial into a production-grade MP4 video with natural speech narration, synchronized karaoke captions, and embedded chapter markers—using the exact same `TutorialSpec` that powers the interactive player. Runs entirely on CPU with zero GPU assumptions, supporting both 16:9 Landscape (1920×1080) for desktop/YouTube/docs and 9:16 Portrait (1080×1920) for mobile/Shorts with intelligent highlight-centered framing.

![Krama v1.2: Video export as MP4 with narration, chapters, and captions](https://github.com/NachikethaKG/Krama/releases/download/v1.2/krama-v1.2-video-export.gif)

## What's in it

- **Remotion Video Exporter Package (`@krama/video-exporter`, #122, #123):**
  - Remotion composition (`TutorialComposition`) driving video frames directly from `TutorialSpec`.
  - High-fidelity vector cursor animation along cubic Bézier paths with click wave ripples.
  - Animated pulsing step highlight boxes and smooth camera zoom transforms.
  - Synchronized burned-in karaoke captions highlighting active words matched to narration timestamps.
  - WebVTT caption file generator (`generateWebVtt`) for standalone `.vtt` downloads.
  - FFmpeg metadata generator (`generateFfmpegChapters`) embedding standard chapter markers for all tutorial steps into the MP4 container.
  - Intelligent framing algorithm (`calculateFraming`): transforms 16:9 viewport coordinates into 9:16 portrait canvas keeping active step targets centered with safe boundary margins.
- **CPU Narration Pipeline with Piper TTS (`backend/app/tts/`, ADR 0004):**
  - Piper TTS running on CPU generating high-quality speech per step without external API calls or latency spikes.
  - Pinned voice model: `en_US-ljspeech-medium` under the permissive Public Domain / CC0 license (ADR 0004).
  - Phoneme- and word-level alignment producing precise timestamp manifests for speech-synchronized captions and dynamic step hold durations.
- **Export Queue & Remotion Renderer Job (`backend/app/export/`, #126):**
  - Dedicated arq job queue `krama:exports` isolating video rendering from web API requests.
  - `RemotionRenderer` launching Node subprocess with bundle caching and CPU thread constraints (`--concurrency=1`, `--gl=angle`/CPU).
  - Live progress reporting advancing deterministically through job lifecycle stages (10% setup, 20% bundle, 30–95% render, 98% metadata insertion, 100% ready).
  - Resilient error trapping mapping subprocess crashes or timeouts to contract-defined error codes (`render_failed`, `timeout`, `narration_failed`).
- **Export MP4 Dialog with Progress & Download (`frontend/components/export/`, #127):**
  - Modal integrated into `TutorialPlayer` with 16:9 Landscape and 9:16 Portrait preset selector cards.
  - Real-time polling (`getExport`) with smooth progress bar and stage status announcements.
  - One-click downloads for finalized MP4 video and standalone WebVTT captions (`.vtt`).
  - Stat displays showing duration, file size, and preset resolution.
  - Error state handling with actionable retry controls on render failures or expirations.
- **Storage Lifecycle & Retention Cleanup (`backend/app/storage/`, #125):**
  - Automatic expiration and disk hygiene enforcing retention rules: exports pruned after 30 days (`EXPORTS_RETENTION_DAYS`) or when disk exceeds 5GB (`EXPORTS_MAX_GB`).
  - Failed partial files removed immediately to prevent disk accumulation.
  - Daily arq cron cleanup worker (`03:30`) plus CLI command `krama exports cleanup [--dry-run]`.
