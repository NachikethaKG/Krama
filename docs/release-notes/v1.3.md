# Release `v1.3` (Phase 6 Assist)

Release: https://github.com/NachikethaKG/Krama/releases/tag/v1.3 · Tag: `v1.3`

Phase 6 makes Krama work alongside you:
- It runs a stored tutorial for you in your own account.
- It hands you the page when it needs a person.
- It finds the right tutorial when you search.
- It speaks more than English.

Everything runs on a 16 GB CPU-only laptop, using free tiers only.

## What's in it

- **Do it for me (#129):**
  - Run any verified tutorial with your own values. The tutorial's inputs (names, titles, text) come from its steps.
  - Each value is checked before the run, then put into the steps.
  - Starting the run approves its steps.
  - Risky steps (delete, publish, security changes) still pause for your confirmation.
  - No new tutorial is stored.
- **Your own account on each site (ADR 0007):**
  - Sign in once per site, by hand, in Krama's browser.
  - Krama stores the session encrypted (`KRAMA_STORAGE_KEY`), never your password.
  - Do it for me then acts in your account. A tutorial recorded in another account is adapted by swapping only the
    account's path segment.
- **Human takeover (#131, ADR 0008):**
  - When a run hits a login wall, a CAPTCHA, or a step Krama can't finish, you take over the live page in the
    browser, then hand it back.
  - Hand-back modes: "I cleared what was in the way", "I did this step", "I finished the task".
  - Krama checks the result either way.
  - The live view is a screencast kept in memory only.
  - The browser stays on the site and its sign-in pages.
  - A takeover ends after 5 minutes without input.
  - Krama never solves CAPTCHAs.
- **Search your tutorials (#135):**
  - Postgres full-text plus trigram search over titles, requests and step text.
  - Results ranked by match × status × freshness, so outdated tutorials rank below verified ones.
  - A small general synonym map (repo → repository, PR → pull request, …).
  - Highlighted snippets that point to the matching step.
- **Languages (#132, ADR 0009):**
  - The app in English, Hindi and Kannada. Pick it from the header; it's stored in a cookie.
  - Every tutorial can be translated on demand into Hindi, Kannada, German, Spanish or French.
  - Quoted UI labels ("Create Repository") stay exactly as on the page.
  - Narration in German, Spanish and French uses licensed Piper voices.
  - Hindi and Kannada get captions only, never an English voice reading them.
  - Video export in any of these languages, with bundled Noto fonts.

## Exit gate (#431), 2026-11-21

Run on Vishwas's laptop with real Gemini and GitHub. Full numbers: [`phase-6-exit-gate.md`](../research/phase-6-exit-gate.md).

| Criterion | Result |
|---|---|
| Do it for me: ≥ 8/10 Gitea replays with new values, checked in Gitea | 8/10, plus 2/2 extra |
| Every destructive step pauses | each of 38 attempts paused before acting |
| No secrets in artifacts | none found in 12 runs |
| One GitHub run | a branch created and confirmed through the GitHub API |
| Takeover: a sign-in wall finished by hand, then resumed and completed | yes, for Gitea and GitHub |
| Takeover memory | about 225 MB extra (limit 300 MB) |
| Search: right workflow in the top 3 for held-out queries | 11/12 (needs 10) |
| Search p95 at 1,000 workflows | 70–77 ms (limit 100 ms) |
| UI in English and Hindi; tutorial in Hindi (captions), exported in German (narrated); labels unchanged | yes |

The gate found and fixed 12 bugs (#450). Among them:
- Exports ignored their language.
- Search was slow at 1,000 workflows.
- The app never left mock mode in development.
- The takeover live view dropped its connection every second.
- The Gitea sign-in check could never pass.

## Known issues

- Signing in for Do it for me is confusing: the pause shows "Continue", and the finished sign-in looks like a failed
  run (#451).
- The planner can guess the names of dialogs it hasn't seen, which fails a step that worked (#449).
- Stored translations aren't refreshed when the translation prompt changes (#448).
- A tutorial step done by hand ("do it yourself") wasn't shown live at the gate; it's covered by the takeover tests.
- Hindi and Kannada texts need a native reader.
