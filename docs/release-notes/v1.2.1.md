# Release `v1.2.1` (Phase 5 Video Export, working)

Release: https://github.com/NachikethaKG/Krama/releases/tag/v1.2.1 · Tag: `v1.2.1`

`v1.2` was tagged before video export worked end to end. This release makes it work and records a live re-check of
the Phase 5 exit gate (#128) on Vishwas's laptop. Fixes in #376:

- **The renderer bundles and renders real tutorials**: webpack resolves the exporter's `.js` imports; local
  screenshots and narration clips are served from the bundle's public folder.
- **Chapters inside the MP4** (Intro, Step 1..N, Done) as a `moov/udta/chpl` box, written in place (no extra ffmpeg).
- **Scenes follow the narration (D4)**: `max(recorded action, 300 ms + clip + 400 ms)` in whole frames, so no line is
  cut and steps get a pause; word timings reach the captions (word-by-word highlight).
- **The real queue**: with `RUN_EXECUTOR=arq`, `krama worker` runs exports on `krama:exports` (one at a time, no
  retry, `EXPORT_TIMEOUT_SECONDS`, startup recovery); in-process mode renders in the API, one at a time. The mock queue
  is only used in tests; no configured queue answers 503.
- **Outro** says the site's host and the date the version was verified.
